# Uso de herramientas de IA

Conforme al enunciado del proyecto (uso responsable de la IA), el equipo declara:

| Herramienta | Para qué se ha usado |
|---|---|
| Claude Code (Anthropic) | Asistente de programación en modo *pair programming* (agente como desarrollador junior): reorganización del repositorio, implementación de entidades, servicios, vistas y pruebas, y redacción de borradores de la documentación. |

## Reglas del equipo

- La IA **asiste**, no es un miembro del equipo: la responsabilidad de cada decisión y de cada línea es de una persona.
- Todo lo generado se revisa antes del *commit*; quien firma el commit responde de él.
- Los requisitos salen de hablar con el cliente (el profesor), no de un *prompt*. Las reglas de dominio no
  confirmadas se anotan como supuestos en [`requisitos.md`](requisitos.md).
- Cada integrante debe poder explicar y modificar cualquier parte del código en la defensa: el código es simple, explícito y está comentado.
- Las convenciones que se le dan a la IA están en [`AGENTS.md`](../AGENTS.md).
